# Проверка фильтра после первого Colab-прогона

Изменения: частичный cuboid_singleview не используется как измерение глубины; сохраняется исходное измерение и причина отказа. Смена номера камеры в ground-режиме проходит обычную проверку согласованности вместо безусловного сброса. Реальная смена опорной точки/режима и подтверждённая повторная фиксация по-прежнему могут создать новый сегмент.

Добавлен независимый счётчик `independent_depth_age_s`: только измерение с `metric_depth_observed=True` (для старых журналов — triangulated) обновляет его. `depth_support_age_s` и совместимое `depth_age_s` показывают возраст поддержки расстояния, включая полный силуэт с ранее оценённым размером. Это разные показатели: размер даёт ограничение масштаба, но не новую многокамерную глубину.

Жёсткое истечение всех однокамерных оценок через 5 секунд проверено и отклонено: на замороженных измерениях покрытие падало до 847/1001, RMSE росла до 13.77 м. Принятый вариант сохраняет полноценную оценку расстояния по размеру.

Проверка: 159 тестов, 16 subtests. Добавлены проверки отказа от частичного силуэта даже при нулевой пиксельной ошибке, разных часов глубины и отсутствия телепортации при смене камеры.

Диагностический повтор measurements из 20261104T173318.532192Z:

| Метрика | Старый фильтр | Новый фильтр |
|---|---:|---:|
| Координаты / 1001 | 1001 | 989 |
| RMSE на доступных парах, м | 13.3394 | 13.1845 |
| RMSE на одинаковых 987 парах, м | 13.1399 | 13.1845 |
| Попадания <=5 м / 999 валидных кадров, % | 4.3043 | 4.5045 |
| Скачки >10 м между соседними доступными кадрами | 2 | 1 |

Это **не доказательство улучшения общей точности**: есть потеря покрытия, а на одинаковой выборке RMSE чуть хуже. Повтор использует исходные измерения, которые были сформированы с прежними prior, размерами и детекциями. Для полной оценки нужен новый запуск Engine, включая обратное влияние фильтра на ShapeEstimator. `scripts/replay_world.py` воспроизводит диагностический расчёт, не обращаясь к эталону до завершения фильтрации.

Обучающий Colab во время изменения кода не перезапускался. После окончания обучения и сохранения весов перезапустить сеанс, выполнить ячейки 1–5; сначала старые веса, затем новые при тех же настройках. Не сравнивать front и center как одну метрику. Реальные размеры ассета и смысл pivot ещё не подтверждены; константы по тестовому эталону не подбирались.
