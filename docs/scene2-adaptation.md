# Адаптация детектора для scene2

Базовый COCO-детектор и модель, обученная на прежней синтетике, плохо распознавали
белый грузовик в новой сцене. Предыдущий прогон с ложными детекциями остановлен;
его координаты не следует использовать как финальный результат.

## Разметка и проверка

Из девяти камер выбраны кадры через 75 кадров исходного видео. Разметка выполнена
визуально по изображению: прямоугольник видимой части грузовика без тени.
Неоднозначные случаи исключены, а не объявлены фоном.

222 исходных изображения: train 169 (40 с грузовиком), val 18 (6 с грузовиком),
test 35 (7 с грузовиком). Для каждого момента времени все камеры принадлежат
одной выборке. Дополнительные обрезки создаются только для положительных train:
80 изображений, всего 249 обучающих изображений. Val/test содержат полные кадры.

Это маленькая проверка на отложенных кадрах **той же сцены**. Близкие моменты
одного ролика коррелированы; результат не доказывает перенос на новые сцены.
Ручные прямоугольники приближённые. Test не используется для выбора эпохи.

## Запуск в Colab

Архив `MyDrive/Peleng-Colab/scene2-adaptation.zip` содержит `annotations.json`
и скрипт запуска. Видео уже распакованы в `/content/peleng-scene2/datasets/scene2`.

```sh
python -u scripts/adapt_scene_detector.py \
  --source /content/peleng-scene2/datasets/scene2 \
  --annotations /content/scene2-adaptation/annotations.json \
  --dataset /content/scene2-detection-v1 \
  --weights /content/drive/MyDrive/Peleng-Colab/yolo11s.pt \
  --output /content/drive/MyDrive/Peleng-Colab/scene2-adaptation-v1
```

YOLO11s, 960 px, batch 8, до 60 эпох, early stopping 15, заморожены первые
10 слоёв. Лучшие веса выбираются по val. Прогресс отображается в новой ячейке
`scene2: обучение по проверенной разметке` исходного блокнота.

Скрипт сохраняет mAP, а также TP/FP/FN, precision/recall при confidence=0.2,
IoU=0.5, изображения предсказаний с зелёными эталонными 2D-рамками и SHA256 весов
и разметки. Папку датасета для нового запуска нужно менять, чтобы не смешать
старую разметку с новой. Веса и видео не публикуются в Git.

После визуальной проверки детектора новые веса передаются `scripts/predict_scene.py`.
Для scene2 нет эталона 3D: доступность координат, разрывы и скачки траектории
являются диагностикой, а не точностью в метрах или процентом правильных 3D-точек.

## Результат адаптации 4 ноября 2026

Обучение остановлено автоматически после 16 эпох. Лучшая эпоха по val mAP50-95 —
первая. Однако при рабочем confidence=0.20 её val TP/FP/FN = 5/1/1,
а у последней эпохи = 6/3/0. Поэтому рабочую конфигурацию выбрал отдельный
`scripts/select_scene_detector.py`: максимум F1 на **val**, с приоритетом precision
при равенстве. Проверены best/last и пороги 0.05–0.80. Test не участвует в выборе.

Выбраны `detector/weights/last.pt` и confidence=0.50. SHA256:
`b996bed291c04e6609b4bc2a0bfc0d18a1352ae32fdbe14d3c7bd93c78a69fee`.

|---|---:|---:|---:|---:|---:|---:|
| Val (подбор параметров) | 18 | 6 | 0 | 0 | 100% | 100% |
| Отложенная test | 35 | 6 | 1 | 1 | 85.7% | 85.7% |

IoU=0.5. Это детекция 2D-рамок; val-цифры оптимизированы подбором параметров,
а test содержит всего семь положительных примеров той же сцены. Не переносить
эти проценты на точность 3D или на другие сцены. mAP первоначального `best.pt`
не относится к выбранному `last.pt`; не смешивать их в презентации.

Результаты: `MyDrive/Peleng-Colab/scene2-adaptation-v1/selected_evaluation`.
Правило выбора, кандидаты и SHA256: `selection.json`. Для восстановления
траектории передавать `--confidence 0.5` вместе с выбранными весами.

На тех же 35 test-кадрах исходная COCO YOLO11s при старом пороге 0.20 дала
TP/FP/FN=1/0/6, предыдущая YOLO11m с синтетики — 0/135/7. Сравнение отражает
рабочие конфигурации до и после адаптации (пороги различаются).
У выбранной модели mAP50=0.9304 и mAP50-95=0.6635. Метрики mAP из
`selected_test_map.json` рассчитаны по диапазону порогов; precision/recall
при фиксированном 0.50 брать из `selected_evaluation/test_fixed_threshold.json`.

Полный прогон `20261104T191657.704939Z` завершён: 1932/1932 кадров,
1811 кадров с координатами (93.74%), из них 1518 observed и 293 coasting;
121 lost. Четыре скачка >10 м (кадры 89, 411, 434, 1834) совпадают с

Следующая задача: повторный захват и согласование масштаба/камер, а не

это последовательная обработка записи, не доказательство работы в реальном времени.
