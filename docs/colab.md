# Запуск на GPU в Colab

Откройте `notebooks/peleng_colab.ipynb` через Colab. Выберите T4 и выполняйте ячейки 1–5 по порядку. Локальный GPU и веб-сервер не нужны: камеры и отчёт отображаются в ноутбуке.

Данные владельца уже загружены в `Мой диск/Peleng-Colab`: шесть наборов, манифест с SHA256 и `yolo11s.pt`. При подключении Drive Google может запросить разрешение пользователя. Ячейка 2 проверяет контрольные суммы и распаковывает данные на диск среды Colab. Веса и данные не входят в публичный репозиторий.

По умолчанию запускаются organizer, YOLO11s, размер 960, опорная точка center. Для сравнения моделей повторяйте ячейки 3–5 с одинаковым набором и опорной точкой. Прогоны на одном GPU последовательные. После изменения кода перезапустите среду, чтобы обновились импортированные модули.

Результаты сохраняются в `Peleng-Colab/runs`: траектория в метрах, наблюдения, превью камер, HTML, ошибки по осям и 3D, MSE/RMSE, доли попаданий в допуски 1/2/5/10/15/20 м, сведения об окружении. Эталон читается только после расчёта траектории. Пропущенные оценки не считаются успешными попаданиями.

Последний раздел содержит необязательное дообучение детектора, выключенное по умолчанию (`TRAIN=False`). Разделение по сценам: train — valley/occlusion/moving, val — stop-go, test — reverse. Это эксперимент с детекцией; улучшение геометрии и ошибки Z требует отдельной проверки.

При полном отключении среды несохранённый текущий прогон может потеряться. Завершённые прогоны остаются в Drive. Это перенос текущего алгоритма; прежние метрики для front не являются результатами нового запуска center.
